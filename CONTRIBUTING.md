# Contributing Guidelines

Thank you for your interest in contributing to this cybersecurity portfolio!

## Before You Start

This is a personal portfolio project. Contributions should:
- Enhance the portfolio's quality
- Add new security tools or scripts
- Improve documentation
- Fix bugs or errors
- Suggest improvements

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch** (`git checkout -b feature/amazing-feature`)
3. **Commit your changes** (`git commit -m 'Add amazing feature'`)
4. **Push to the branch** (`git push origin feature/amazing-feature`)
5. **Open a Pull Request**

## Code Standards

### Python
- Follow PEP 8 style guidelines
- Use type hints where applicable
- Add docstrings to functions
- Test code before submission

### Bash Scripts
- Use shellcheck for validation
- Add error handling
- Include comments for complex logic
- Make scripts portable (use /bin/bash)

## Documentation

- Update README.md if adding new features
- Include usage examples
- Document dependencies
- Explain security implications

## Security Considerations

⚠️ **Important:**
- Never commit sensitive information
- Don't include real credentials or API keys
- Use .env files for configuration
- Review security implications of changes
- Follow responsible disclosure practices

## Testing

- Test scripts in isolated environments
- Document test scenarios
- Include example output
- Verify no breaking changes

## Pull Request Process

1. Update documentation
2. Test thoroughly
3. Provide clear description
4. Reference related issues
5. Ensure no sensitive data is included

## Questions?

Feel free to open an issue to discuss ideas or ask questions.

---

**Thank you for contributing!** 🔐
